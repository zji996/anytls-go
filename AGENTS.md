# Repository Instructions

## Tools

- Prefer `rg` for content search, `fd` for file discovery, and `bat` for file reading.
- Prefer `sg` for structured search and refactoring.
- Use `fzf` when interactive selection is needed.

## Commits

- After completing one clearly scoped task and verifying it, create a commit without asking for additional confirmation.
- Keep each commit limited to that task; do not mix unrelated changes.
- Before committing, run the checks relevant to the changed behavior and report any check that could not be run.
